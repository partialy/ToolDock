# 视频处理

视频处理提供「提取音频」「生成字幕」两个工作区。媒体只在本机处理，不上传音视频，不依赖 Python。切换工具或关闭主窗口到托盘后，主进程继续处理；正式退出会取消处理。

## 输入与输出

- 支持多选、拖入文件或文件夹、选择文件夹；文件夹只扫描直接子文件，不进入子目录。导入时按真实路径去重并显示跳过原因。
- 提取音频接收视频，字幕接收音频和视频。探测后可逐文件选择音轨。
- 默认 MP3 192kbps，也支持 WAV、FLAC、M4A 和复制原音轨。复制时按编码选择兼容扩展名，不会将 AC3/Opus 伪装成 M4A。
- 默认输出原目录，可选择其他输出目录。重名自动追加 `(1)` 等后缀，绝不覆盖原文件或已有输出。
- 提取音频并发上限为 2，字幕串行识别。可以取消、重试，清理终态记录。SQLite 只保存任务路径和状态等元信息，最近最多保留 100 条终态记录。
- 异常退出的未完成任务在下次启动时标记中断，需手动重试。

## 本地字幕与模型

在模型管理中下载多语言 Tiny、Base、Small、Medium 或量化模型，默认推荐 Small。模型不随安装包提供。下载完成后核对长度与 SHA-256，通过验证才作为已安装模型使用。

模型管理支持离线导入、引用外部文件、删除与自定义保存目录。引用外部模型时不会删除源文件。自定义模型会显示来源未验证。目录迁移或模型维护前需停止媒体任务；迁移采用复制、校验后切换配置，失败不切换旧配置。

下载默认直连；可单独开启 `proxy-d.partialy.cn` 加速，默认关闭。代理失败重试后回退直连。旧代理不支持 HEAD 时使用 Range GET 探测；只有范围和版本元数据有效时才并行下载，默认 4 段、最多 8 段。暂停后可恢复，取消不产生可用模型。

字幕语言提供自动、中文、英文。识别前在本机转为 16kHz 单声道 PCM，保留原始时间轴。生成后可预览 SRT、另存及打开输出目录。本版本不提供字幕编辑、翻译、烧录或说话人区分；识别结果仍需人工校对。

## CPU 与 CUDA

安装包包含 CPU Whisper 引擎；CUDA 引擎在模型管理中按需安装，使用固定版本官方 GitHub 发布资产，并校验 SHA-256。无需安装 Python。

当前锁定 whisper.cpp v1.8.3 的完整 CUDA 12.4 Windows 包（约 439 MiB），包含相应运行库；未采用缺少运行依赖的 CUDA 11.8 资产。RTX 3050 Ti 已通过 Tiny 模型的真实识别及应用内安装链路检查。短音频或小模型不保证 GPU 比 CPU 更快。

- 自动：优先使用已安装的 CUDA 引擎；GPU 初始化、运行库或显存失败时提示原因并重试 CPU。
- GPU：要求实际 CUDA 初始化成功，失败直接报告，不静默降级。
- CPU：禁用 GPU，使用随包 CPU 引擎。

任务显示实际使用设备与回退原因。安装 CUDA 文件不等于显卡可以运行：驱动、运行库、模型和显存均可能影响结果。4GB 显存建议先尝试 Tiny/Base/Small，避免直接使用 Medium。

## 构建与资源

执行 `npm run fetch:media` 获取锁定的 LGPL FFmpeg/ffprobe 和 whisper.cpp CPU 二进制；`npm run dist` 在构建安装包前获取并校验资源。资源在 `resources/media/bin`，不提交 Git，通过 Electron extraResources 放入安装包；不复制开发机器上的 FFmpeg。

资源版本、资产 URL 与 SHA-256 记录在 `resources/media/binaries.lock.json`，获取脚本保留许可证和来源说明。CUDA 按需安装文件、模型及处理缓存不纳入普通备份；媒体设置、任务记录与离线模型导入/引用元信息随 SQLite 备份。数据目录迁移/恢复和媒体操作互斥，防止任务执行时更换存储位置。

数据目录迁移先在目标同级的专属临时目录复制并校验数据库，再以排他创建方式写入空目标，全部完成后原子切换启动定位。用户选定的目标目录不会被递归删除；失败时恢复原数据库，目标中已经复制的内容和用户新写文件均保留，需检查后另选空目录重试。迁移拒绝符号链接/Junction 目标或带链接的数据内容，原数据目录始终保留。

开发测试必须使用隔离用户数据目录，不覆盖正式安装版数据库。代理服务的线上部署属于独立流程，本功能不会部署或修改 Cloudflare Worker。
